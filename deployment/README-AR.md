# نظام قدرات الحرس الوطني: التثبيت على الجهاز الافتراضي المعزول

هذه الحزمة فيها كل ما يحتاجه النظام، ولا تحتاج إنترنت. الشرح الكامل لفريق تقنية المعلومات في `README.md`.

## المطلوب على الجهاز الافتراضي

- نظام Linux عليه **Docker** يعمل، و**nginx** (إن لم يوجد nginx تشغّل الحزمة nginx خاصاً بها).
- صلاحية root (أي `sudo`).
- اختياري: شهادة HTTPS من فريق تقنية المعلومات (`certs/README.md`). بدونها تُنشأ شهادة مؤقتة ويظهر تحذير في المتصفح.

## التثبيت: ثلاثة أوامر

```bash
tar -xzf cpc-<version>.tar.gz
cd cpc-<version>
sudo ./install.sh
```

يسأل أربعة أسئلة (اضغط Enter لقبول القيمة بين القوسين):

1. **الاسم الذي يكتبه المستخدمون في المتصفح**: اسم الجهاز أو عنوانه (IP).
2. **قاعدة البيانات**: `1` القاعدة المدمجة (ملف داخل `/opt/cpc/data`، تبدأ بها الآن وتنتقل إلى Oracle لاحقاً من الإعدادات)، أو `2` Oracle (بيانات من مسؤول قاعدة البيانات).
3. **اسم أول مدير نظام** (مثل رقم U).
4. **كلمة مروره** (مرتين، ولا تظهر على الشاشة).

ثم يكمل وحده:
- يحمّل النظام ويشغّله.
- يضيف الموقع إلى nginx بعد أن يتأكد أن الإعدادات سليمة.
- ينشئ أول مدير نظام والقوائم الأساسية.
- يجهّز النسخ الاحتياطي الليلي.

في النهاية يطبع رابط الموقع.

البيانات تبدأ **فارغة**: لا بيانات تجربة ولا حسابات `mock`. بعد الدخول أضف القائد ورؤساء الشعب والمستخدمين من الإعدادات ← «المستخدمون»، واحداً واحداً أو بملف Excel.

## بعد التثبيت

| ماذا تريد | الأمر |
|---|---|
| حالة النظام والرابط | `sudo /opt/cpc/scripts/app.sh status` |
| إعادة التشغيل | `sudo /opt/cpc/scripts/app.sh restart` |
| نسخة احتياطية الآن (وتؤخذ تلقائياً كل ليلة) | `sudo /opt/cpc/scripts/app.sh backup` |
| سجل النظام | `sudo /opt/cpc/scripts/app.sh logs` |

- **النسخ الاحتياطية** في `/opt/cpc/backups`. انسخها خارج الجهاز بانتظام.
- **التحديث بإصدار جديد**: فك الحزمة الجديدة وشغّل `sudo ./install.sh` منها. يأخذ نسخة احتياطية أولاً، ويحتفظ بالإعدادات والبيانات.
- **الدخول بحساب Windows**: من الإعدادات ← «تسجيل الدخول ودليل الشركة»، ببيانات من فريق تقنية المعلومات (`docs/SETTINGS.md`).
- **الانتقال إلى Oracle لاحقاً**: من الإعدادات ← «قاعدة البيانات». قاعدة Oracle تبدأ فارغة، وبيانات التجربة لا تنتقل إليها أبداً.
